# Skills and Technologies

This document outlines the key skills and technologies demonstrated in the **Lipun Rout — Portfolio** project.

## Core Skills
- **Frontend Development**: Expertise in building modern, responsive, and interactive user interfaces.
- **TypeScript**: Strongly typed JavaScript for better code quality and maintainability.
- **React**: Component-based architecture for building dynamic web applications.
- **Next.js**: Server-side rendering (SSR) and static site generation (SSG) for optimized performance.

## Styling and Animations
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development.
- **GSAP + ScrollTrigger**: Advanced animations and scroll-based interactions.
- **Lenis**: Smooth scrolling for enhanced user experience.

## Tools and Libraries
- **Lucide**: Lightweight and customizable icon library.
- **Playwright**: Automated browser testing and screenshot generation.
- **Vercel**: Seamless deployment and hosting platform for Next.js applications.

## Architecture and Design
- **Component-Based Design**: Modular and reusable components for scalability.
- **Motion Optimization**: Motion toggle with `MotionProvider` to respect user preferences (`prefers-reduced-motion`).
- **Server Components**: Leveraging Next.js App Router for server-side rendering and improved performance.

## Development and Deployment
- **Version Control**: Git and GitHub for source code management.
- **Environment Variables**: Configuring `NEXT_PUBLIC_SITE_URL` for dynamic social-share URLs.
- **Automated Builds**: Production builds with linting and type-checking.

## Additional Skills
- **Responsive Design**: Ensuring compatibility across devices and screen sizes.
- **Accessibility**: Respecting motion preferences and ensuring content visibility without animations.
- **Image Optimization**: Using placeholders and automated screenshot generation for project images.

This project demonstrates a strong foundation in modern web development, focusing on performance, accessibility, and user experience.
